Kenetre
=======

Kenetre is a Java multi module library that is used by both [Aozan](https://www.outils.genomique.biologie.ens.fr/aozan/) and [Eoulsan](https://www.outils.genomique.biologie.ens.fr/eoulsan/) projects.

The current avaiblable modules are :
- **kenetre-bin**: a collection a small programs;
- **kenetre-bio**: sequencing dedicated classes;
- **kenetre-core**: core utility classes;
- **kenetre-docker**: Docker related classes
- **kenetre-expressioncounters**: expression counter classes;
- **kenetre-extra**: extra classes;
- **kenetre-illumina**: Illumina dedicated classes (e.g. samplesheet manipulation classes);
- **kenetre-it**: integration test system;
- **kenetre-mappers**: mapper wrappers and binaries;
- **kenetre-nanopore**: Nanopore dedicated classes (e.g. Fast5 manupulation class);
- **kenetre-storages**: storage classes;
- **kenetre-translators**: translator related classes.
